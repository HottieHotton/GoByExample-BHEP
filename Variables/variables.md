I find it very interesting that you can do var, int, string, etc in both inside and outside a function. However, you can't do := outside a function, only inside.

For notes:
:= auto assigns type, while you can manually assign via the other method(var a int, var b string, etc).

ALSO: You can assign multiple variables at once in one line, which I find very interesting. You can do it like this: var a, b, c = 1, 2, 3. This is the same as var a = 1, b = 2, c = 3. This can be helpful when you're grouping types together for example for cleaner code.
